# Zero-Shot Balancer

This directory contains the documentation for the Zero-Shot Balancer project.

- [Developer guide](/docs/developer_guide/README.md): quickstart for setting up the Python environment and running tests.
- [Python and uv](/docs/developer_guide/python-uv.md): installation, package management, Python versions, and dependency locking.
- [Creating MJCF files](/docs/Report_on_MJCF.md): robot model structure, physical parameters, actuators, and sensors in MuJoCo.
- [Unit tests](/docs/unit_tests.md): observation and action test cases, scope, and instructions for running pytest.
