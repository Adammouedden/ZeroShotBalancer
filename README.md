# Zero-Shot Balancer

This repository contains all open-source code & documentation for the Zero-Shot Balancer project, which is an out-of-distribution generalized test for a self-balancing robot trained in a physics engine with reinforcement learning which is then deployed onto a microcontroller to balance a real robot

The repository is split into two src code directories:
1. [Embedded Systems](src/embedded_systems)
2. [Machine Learning](src/machine_learning/)
